# 과학연구자 대상 AI운영환경(AI-OS) 시범 서비스 개발 용역

- 기관: 국가과학기술연구회
- 예산: 7.6억
- 마감: 2026-12-16 10:00
- 개찰: 2026-12-16 11:00
- 분류: 생성형·Agent · 시스템 구축·고도화

## 개요
과학기술 분야 정부출연연구기관 및 과학연구자를 대상으로 표준화된 AI운영환경(AI-OS) 시범 서비스를 개발하고 검증하는 사업입니다. 실행환경, 모델운영, 연구자산관리, 연구지원 에이전트, 공통관리·보안 5개 영역의 핵심 기능을 구축합니다. 클라우드 인프라와 외부 인프라 구간의 이원 구조로 환경을 조성하여 연구 전주기를 지원합니다.

## 과업
- AI-OS 기능 영역별 표준규격 및 보안 아키텍처 확정
- 컨테이너 오케스트레이션 및 GPU 자원 풀 관리 기능 구축
- 모델 레지스트리 및 멀티모델 라우팅 연계 체계 개발
- 연구자산 카탈로그, 메타데이터, 계보, 데이터레이크 구축
- 공통 Agent Runtime 및 연구 지원 에이전트 3종 개발
- 연구자 워크스페이스 포털 및 통합 관리자 콘솔 구축

## 요구 기술
- Kubernetes
- LLM
- MCP
- GPU 서버
- 클라우드 IaaS
- IaC

## 평가
기술능력평가 90%와 입찰가격평가 10%를 합산하여 고득점자 순으로 협상을 진행하는 협상에 의한 계약 방식입니다.
