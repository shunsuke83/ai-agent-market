핵심 발견

1. 경쟁의 중심이 "에이전트를 만드는 도구"에서 "에이전트를 통제하는 체계"로 옮겨갔습니다

2026년 글로벌 3사는 모두 에이전트 ID, 레지스트리, 정책 엔진을 GA했습니다(AWS AgentCore Identity·Policy·Registry, MS Entra Agent ID·Agent 365, Google Agent Identity·Registry·Gateway). 에이전트 수가 늘면서 생긴 "에이전트 난립(sprawl)"을 통제하는 것이 핵심 과제가 됐습니다.

2. MCP와 A2A가 사실상 표준이 됐습니다

MCP(에이전트-도구)와 A2A(에이전트-에이전트)가 모두 Linux Foundation 산하 Agentic AI Foundation으로 들어갔습니다. 국내에서도 삼성SDS·LG CNS가 MCP·A2A를 지원하고, 범정부 공통기반 2차는 기존 시스템을 MCP 서버로 전환하는 방향을 제시했습니다.

3. 모델은 "하나를 고르는 것"이 아니라 "여럿을 라우팅하는 것"이 됐습니다

MS Model Router, LG CNS 라우터, 삼성SDS FabriX 2.0 자동 선택, KT 토큰팩토리처럼 모두 멀티 LLM에 라우팅·폴백을 붙입니다. 범정부 공통기반 2차도 AI 게이트웨이로 플랫폼사 모델 종속을 줄이는 쪽으로 바뀌었습니다.

4. 평가·최적화 루프가 플랫폼 기본 기능이 됐습니다

글로벌 3사는 관측 → 평가 → 시뮬레이션 → 최적화를 한 서비스 안에서 제공합니다. 국내 SI는 토큰·비용 모니터링(FinOps) 수준이 중심이고, 자동 평가·최적화 루프는 아직 공개 정보가 적습니다.

5. 국내 공공은 "공통기반 SaaS + 부처별 에이전트" 구조로 굳어지고 있습니다

삼성SDS(FabriX)와 네이버클라우드(클로바 스튜디오 for Gov)가 공통기반 플랫폼을 선점했습니다. LG CNS·KT는 기관별 대형 구축형(외교부 300억, 경기도교육청 380억, 대법원 145억)에서 앞서 있습니다. 글로벌 3사는 CSAP 하등급까지만 갖고 있어 행정망 사업에는 직접 들어오기 어렵습니다.

업체별 특징과 공공 공략 방식

AWS

모델·프레임워크 중립 인프라

  • AgentCore를 10여 개 서비스로 쪼개 필요한 것만 조합
  • microVM 세션 격리, Cedar 기반 결정론적 정책 통제
  • 공공: CSAP 하등급, 서울 리전에서 AgentCore 핵심 서비스 제공
Microsoft

에이전트를 디지털 직원처럼 관리

  • Entra Agent ID와 Agent 365로 사람과 같은 ID·감사 체계 적용
  • M365·Teams라는 사용자 접점이 최대 무기
  • 공공: CSAP 하등급, KT와 SPC(소버린)로 우회 진입
Google Cloud

풀스택 + 개방형 프로토콜 주도

  • Vertex AI를 Agent Platform으로 개명할 만큼 에이전트 중심 재편
  • A2A·ADK·AP2로 생태계 표준 주도
  • 공공: CSAP 하등급, GDC 에어갭 Gemini가 잠재 카드
삼성SDS

인프라부터 협업툴까지 수직 통합

  • FabriX(허브) + Brity Works(앱) + Brity Automation(RPA) + AI 스토어
  • 자체 프런티어 모델 대신 OpenAI·Google·Anthropic 파트너십
  • 공공: 국정자원 PPP + 공통기반 + 온AI로 표준 플랫폼 선점
LG CNS

6종 모듈형 온프렘 풀스택

  • 빌더·스튜디오·지식 레이크·허브·리파이너·라우터
  • EXAONE 파인튜닝(리파이너)으로 기관 특화 모델
  • 공공: 기관별 대형 구축형(외교부, 경기도교육청)
SK AX

운영 자동화 특화

  • AXgenticWire 브랜드(플랫폼·LLM·데이터·인프라)
  • AIOps 멀티에이전트 장애 대응, BPO·ITO 연계
  • 공공: 직접 수주 확인 안 됨. 금융·제조 중심
네이버클라우드

자체 모델 + 행정망 SaaS

  • HyperCLOVA X → CLOVA Studio → 네이버웍스 수직 통합
  • 개발자용 for Gov 빌더 + 현업용 EASY 이원화
  • 공공: 공통기반 플랫폼 2종 중 하나, FDE 파견으로 에이전트 발굴
KT

멀티모델 브로커 + 부품형 PaaS

  • 믿:음 K, SOTA K, 국산 모델을 토큰팩토리로 연결
  • RAG 스위트·벡터DB를 CSAP 중등급으로 조달
  • 공공: 대법원 145억, 경기도 131억 등 대형 구축형
범정부 AI 공통기반

공공 아키텍처의 기준선

  • 2차(약 65~66억): AI 게이트웨이, 통합 공통 RAG, MCP, N2SF, 행정망-인터넷망 연계
  • 방향: 특정 플랫폼사 종속 완화, 모델 교체 가능 구조
  • 2026.9 개찰 삼성SDS 단독 응찰

업계 표준화 흐름

  • MCP (에이전트 ↔ 도구): 글로벌 3사 모두 기본 연동 표준으로 채택. 2025.12 Linux Foundation 산하 Agentic AI Foundation(AAIF)에 기증됨.
  • A2A (에이전트 ↔ 에이전트): Google이 2025.4 공개, MS는 GA, AWS는 Strands·Marketplace에서 지원. 2026.8 AAIF 합류.
  • 에이전트 ID·레지스트리: 3사 모두 2026년에 GA. 공공 조달에서도 "에이전트 권한·감사"가 평가 항목으로 들어올 가능성이 큽니다.
  • 관측성: OpenTelemetry 기반 에이전트 트레이싱이 공통 형식으로 자리 잡는 중.
  • 신흥 영역: 에이전트 결제(AP2, x402), 운영 규약(AGENTS.md).
