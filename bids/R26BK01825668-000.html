# AI과학자 추론용  로컬 워크스테이션

- 기관: 국가과학기술연구회

## 개요
본 사업은 핵융합 운전시나리오 자율설계 및 방사광가속기 자율시운전 AI과학자 개발을 위한 추론용 로컬 워크스테이션 2대를 구입 및 설치하는 사업입니다. 지정된 고성능 하드웨어 규격에 따라 제조사 정품 신품을 납품하고 Fedora Linux Server OS 환경 및 GPU 호환 세팅을 수행해야 합니다.

## 과업
- AI과학자 추론용 로컬 워크스테이션 납품 및 현장설치
- Fedora Linux Server OS 설치 및 세팅
- GPU 운영 호환 환경 구축 및 검증

## 요구 기술
- NVIDIA RTX PRO 5000 Blackwell
- INTEL Core Ultra 9 285K
- Fedora Linux Server
- DDR5 128GB RAM
- NVMe 4TB / SATA 8TB
- ASUS ProArt Z890

## 평가
규격·가격 동시 입찰 방식으로 규격입찰서 평가 결과 적격자(적합기준점수 100점) 중 예정가격 이하 최저가격으로 투찰한 자를 낙찰자로 선정합니다.
