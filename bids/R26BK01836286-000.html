# 대규모 언어모델(LLM) 데이터 학습 및 고성능 연산을 위한 GPU 연산 서버 구매

- 기관: 제주대학교 산학협력단
- 예산: 2.0055억
- 마감: 2026-12-01 10:00
- 개찰: 2026-12-01 11:00
- 분류: 생성형·Agent · 인프라

## 개요
본 사업은 제주대학교 G-LAMP 연구사업 수행을 위해 고성능 GPU 기반 연구·연산 인프라를 구축하는 사업입니다. 대규모 언어모델(LLM) 데이터 학습 및 AI 융합연구 지원을 위해 4U 랙마운트형 고성능 GPU 연산 서버 1대를 구매 및 설치합니다. 기 운영 중인 기존 서버 8대 및 MLOps 소프트웨어와의 연동과 통합 자원 관리 환경 조성을 포함합니다.

## 과업
- 고성능 GPU 연산 서버 1대 방문 납품 및 설치
- 기존 보유 서버 8대 및 MLOps 소프트웨어 연동
- Ubuntu OS 및 GPU 연산 환경 소프트웨어 구성
- Web UI 기반 GPU 상태 모니터링 도구 구성
- GPU MIG 기능 활용 자원 분할 관리 지원
- 기술지원 및 사용자 교육 이행

## 요구 기술
- GPU 연산 서버
- NVMe SSD
- Ubuntu OS
- CUDA
- Web UI
- MIG(Multi-Instance GPU)

## 평가
규격가격동시입찰 방식으로 규격제안서 평가 결과 85점 이상인 적격자 중 예정가격 이하 최저가 입찰자를 낙찰자로 결정합니다.
