제안요청서 요약

본 사업은 공공기관과 기업의 웹 콘텐츠 운영 관리 기능을 통합 제공하는 생성형 Exo AI-CMS v2.0 상용SW 3자단가계약입니다. 전자정부 표준프레임워크 4.3.0 및 Java 17 기반으로 웹 콘텐츠 운영 구조와 사용자 접근 권한을 관리합니다. 외부 AI API 연계를 통해 프롬프트 기반 게시물 작성 보조 기능을 제공합니다.

주요 과업
  • 게시판 및 게시물 관리
  • 부서 및 사용자 조직 관리
  • 그룹 및 하위 코드 관리
  • 메뉴 및 프로그램 권한 관리
  • 보안 롤 및 접근 권한 관리
  • AI 프롬프트 및 API 연계 관리
요구 기술Java 17, 전자정부 표준프레임워크 4.3, Spring MVC, MyBatis, MariaDB / Oracle, 외부 AI API
자격·요건
  • GS인증 1등급 보유 제품 규격 준수
  • 운영서버 1 Core 단위 SW 라이선스 계약 준수
  • 최소 WAS 서버 사양(4 vCPU, 8GB RAM, 100GB SSD 이상) 충족
  • 제조자 및 공급자의 직접이행의무 준수
유의 사항
  • 직접이행의무 위반 및 브로커 개입 등 불공정행위 시 계약 해지 및 환수 조치
  • API 키 및 DB 비밀번호 등 주요 인증정보의 소스 내 평문 저장 금지
  • 기관별 추가 연계 개발, 디자인, 데이터 이관 등 커스터마이징은 별도 협의 필요
  • 무상 하자보수 기간은 납품 후 1년을 기본 적용
