# 인공지능 기반 열처리 조건 패터닝 플랫폼 개발

- 기관: 한국생산기술연구원
- 예산: 0.66억
- 마감: 2026-11-20 12:00
- 개찰: 2026-11-20 13:00
- 분류: AI SW 확대 · 시스템 구축·고도화

## 개요
본 사업은 참여기업의 열처리 공정 데이터를 활용하여 데이터 기반의 지능형 공정 운영 체계로 전환하기 위한 AI 기반 열처리 조건 패터닝 플랫폼을 개발하는 용역입니다. 제품 형상·중량·소재 특성을 반영한 데이터 분석과 실제 소재 온도 기반의 열처리 조건 예측·추천 및 시각화 기능 구현을 목적으로 합니다.

## 과업
- 열처리 공정 데이터 수집 및 전처리 기능 개발
- 형상·중량·소재 특성 기반 데이터 패턴 분석 기능 개발
- AI 기반 열처리 조건 추천 알고리즘 개발
- 실제 소재 온도 기반 열처리 조건 예측 모델 개발
- 공정 데이터 시각화 및 사용자 인터페이스(GUI) 개발
- 공정 조건별 품질 및 에너지 사용량 분석 기능 구현

## 요구 기술
- AI
- 빅데이터 분석
- GUI

## 평가
기술능력평가(80%)와 입찰가격평가(20%)를 합산하여 기술능력평가 배점한도의 85% 이상인 협상적격자 중 고득점 순으로 협상을 진행하는 협상에 의한 계약 체결 방식입니다.
