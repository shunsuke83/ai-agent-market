# 방과후 AI 강사 인증·관리 기능 개발

- 기관: 한국과학창의재단
- 예산: 5.0억
- 마감: 2026-12-02 10:00
- 개찰: 2026-12-02 11:00
- 분류: AI SW 확대 · 시스템 구축·고도화

## 개요
2027년 '1교 1AI 방과후' 추진에 대비하여 역량 있는 강사를 검증하고 국가 및 지역이 공동 활용할 수 있는 방과후 AI 강사 인증·관리 시스템을 구축하는 사업입니다. SJT 기반 온라인 역량 진단, 자동 채점·인증, 배지 및 레벨 부여, 강사풀 등록 및 검색·섭외 기능을 구현합니다. 또한 표준 인증 모델(OAuth 2.0/OIDC)을 도입하여 통합회원 체계를 개편하고 디지털새싹 사업관리시스템 연동 및 개인정보 보호를 강화합니다.

## 과업
- 방과후 AI 강사 인증 시스템 개발
- SJT 기반 역량 진단 및 자동 채점·인증 구현
- 통합회원 표준 인증(OAuth 2.0/OIDC) 체계 개편
- 디지털새싹 사업관리시스템 및 외부 LMS 연동
- 사용자 권한별 화면 및 반응형 UI/UX 개발
- 개인정보 라이프사이클 및 접속기록 중앙 관리

## 요구 기술
- OAuth 2.0 / OIDC
- REST API / API Composition
- HTML5 / CSS3 (반응형 웹)
- MSA (Microservices Architecture)
- DB 암호화
- Kubernetes / Service Mesh

## 평가
기술능력평가 점수와 가격평가 점수를 합산하여 고득점자 순으로 협상을 진행하며, 기술능력평가 배점한도의 85% 이상 득점자를 협상적격자로 선정합니다.
