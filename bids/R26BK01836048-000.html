# 온라인 AX 수준진단 솔루션 개발 용역

## 개요
구미산단 제조기업의 특성과 규모를 고려한 AX(AI 전환) 수준 진단모델을 마련하고, 기업의 AX 현황 및 역량을 온라인에서 진단·분석·관리할 수 있는 디지털 기반 솔루션을 구축하는 사업입니다. 온라인 자가진단, 현장 실사 결과 통합 분석, 진단 리포트 자동 생성, 지역 제조기업 AX 현황 DB 인프라 구축 등을 수행합니다.

## 과업
- 제조기업 AX 수준 진단모델 개발
- 온라인 AX 수준 진단 솔루션 구축
- 온라인 진단·현장 실사 결과 통합 분석
- AX 진단 결과 요약 및 리포트 자동 생성
- 관리자 통합 대시보드 구축
- 지역 제조기업 AX 현황 DB 관리 구축

## 요구 기술
- 웹 운영 환경(서버/DB)
- 반응형 웹 UI/UX
- PDF 및 엑셀 출력 인터페이스
- API 연계 확장 인터페이스

## 평가
기술능력평가(90%)와 가격평가(10%)를 합산하여 종합평가점수 85% 이상 중 고득점순으로 협상을 진행하는 협상에 의한 계약 방식입니다.
