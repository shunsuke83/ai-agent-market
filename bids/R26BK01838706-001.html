# [혁신] 세한대학교 AX 기반 학술정보 통합서비스 고도화 사업

- 기관: 세한대학교
- 예산: 1.6억
- 마감: 2026-11-30 18:00
- 개찰: 2026-12-01 10:00
- 분류: 생성형·Agent · 시스템 구축·고도화

## 개요
노후화된 기존 C/S 기반 도서관 업무시스템을 SPA 웹 표준 기반으로 고도화하고 모바일 앱과 생성형 AI 기반 검색·챗봇 서비스를 구축하는 사업입니다. 웹 도서관리 및 모바일 앱 운영을 위한 하드웨어 서버 도입, 기존 도서관 데이터 이관, 교내 포털 연동을 함께 수행합니다.

## 과업
- C/S 기반 사서 업무 시스템의 SPA 웹 표준 전환 및 고도화
- Android 및 iOS 지원 하이브리드 모바일 앱 개발
- 자연어 기반 AI 검색서비스 및 24시간 AI 챗봇 구축
- 웹 도서관리 및 모바일 앱 운영용 서버 하드웨어 도입
- 기존 도서관 DB 이관 및 데이터 정합성 검증
- 교내 포털 SSO 및 외부 Open API 연계

## 요구 기술
- SPA 웹 표준
- 생성형 AI / NLP(자연어 처리)
- 하이브리드 앱 (Android/iOS)
- Windows Server 2025 / SQL Server 2025
- QR / NFC / BLE
- Open API

## 평가
기술능력평가(90%)와 입찰가격평가(10%)를 합산하여 평가하며, 기술평가 배점한도의 85%(76.5점) 이상인 자 중 고득점순으로 협상을 진행합니다.
